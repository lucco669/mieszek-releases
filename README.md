# Mieszek: releases

Installers and the automatic-update feed for [Mieszek](https://github.com/lucco669/mieszek-releases/releases/latest), a private, local-first investment tracker for Windows.

- **Download:** [Mieszek_x64-setup.exe](https://github.com/lucco669/mieszek-releases/releases/latest/download/Mieszek_x64-setup.exe) (latest version)
- **Updates:** the app checks `latest.json` here and installs only updates signed with Mieszek's key.

This repository holds release files only. The source code is not public.
